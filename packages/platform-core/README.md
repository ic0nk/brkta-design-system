# `@brkta/platform-core`

Framework-neutral global engines for BRKTA applications.

This package owns pure contracts and deterministic resolvers for theme, locale, RTL direction, currency, money formatting, region, preferences, identity signals, consent, feature flags, date/time, reduced motion, and translation catalogs.

It intentionally has no framework, browser, provider, or backend-domain dependency. Applications provide adapters for DOM theme attributes, storage, routing, authentication, geolocation, analytics, and API-backed settings.
