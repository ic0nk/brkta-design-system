# Component inventory and roadmap

The current component list and package source locations are maintained in the [component registry](component-registry.json). Public component usage guides are in [`docs/components/`](components/); package exports and the published Storybooks are the source of truth for current availability.

## Planned areas

The following are ongoing priorities, not commitments to a specific release:

- Keep Angular and React component behavior and APIs aligned.
- Expand tested accessibility, RTL, and reduced-motion coverage.
- Improve component guidance and examples based on public feedback.
- Add components when they solve a reusable need and fit existing package boundaries.

To request a component, open a [component request](https://github.com/ic0nk/brkta-design-system/issues/new?template=component_request.yml). See [component governance](COMPONENT-GOVERNANCE.md) before contributing.
