## Components and contribution

- Browse the [component documentation](components/) and [component registry](component-registry.json).
- Read [component governance](COMPONENT-GOVERNANCE.md) before proposing a component.
- See the public [component roadmap](ROADMAP.md) for planned documentation and design-system work.
- Review [migrating an existing app from workspace packages](../MIGRATION.md).

For repository setup and contribution checks, see [CONTRIBUTING.md](../CONTRIBUTING.md). Packages install from GitHub Packages; configure a user-level npm token with `read:packages` before running the CLI.
