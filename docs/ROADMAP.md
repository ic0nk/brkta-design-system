# Roadmap

This page tracks broad public design-system priorities. It is intentionally a forward-looking summary, not a historical implementation log. Planned items are not promises or claims of shipped functionality; check the [component registry](component-registry.json) and package exports for current availability.

## Planned

- Continue improving coverage and parity across Angular and React components.
- Expand getting-started examples and component documentation based on contributor feedback.
- Improve public Storybook and visual regression coverage.
- Continue validating contrast, RTL, reduced-motion, and responsive behavior as components evolve.

Suggest or discuss roadmap items through a [GitHub issue](https://github.com/ic0nk/brkta-design-system/issues).
